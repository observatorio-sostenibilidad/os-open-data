# os-open-data

Public open data catalog and distributable datasets for Observatorio de Sostenibilidad.

Licensed under **CC-BY 4.0** unless otherwise noted per dataset.

**Architecture spec:** [os-workspace/SPEC.md](https://github.com/observatorio-sostenibilidad/os-workspace/blob/main/SPEC.md)

## Layout

```
catalog/index.yaml       DCAT-AP-compatible catalog (generated by registry:sync)
catalog/references.yaml  External source references (MITECO, AEMET, CNIG)
datasets/{id}/           Frictionless Data packages
  datapackage.json       Source of truth for os:dataset metadata
  municipios-index.json  Small sidecar files may live in Git (<2 MB)
```

## Storage policy

| What | Where |
|------|-------|
| Metadata (catalog, datapackage, README, small JSON) | **This Git repo** |
| Parquet, GPKG, PMTiles, large GeoJSON | **GCS** `os-{env}-data-public` |
| Local development | Bytes may exist under `datasets/` on disk; `.gitignore` excludes large formats |

Regenerate lock file and catalog from manifests:

```bash
# From repos/os-platform
pnpm registry:sync
```

## Multi-resource geo (CNIG)

CNIG administrative boundaries use multiple `resources[]` per package (GPKG master, GeoJSON, PMTiles). See [geo-dataset-packaging.md](https://github.com/observatorio-sostenibilidad/os-workspace/blob/main/docs/editorial/geo-dataset-packaging.md).

## Standards

- DCAT-AP 3.0 catalog metadata
- Frictionless Data Package manifests + `os:dataset` extension
- Canonical tabular format: Parquet / GeoParquet
- Canonical geo formats: GPKG (master), PMTiles (web)
